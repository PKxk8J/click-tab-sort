## Summary

増えすぎた Firefox のタブを、簡単に URL、タイトル、開いた日時、最後に見た日時、ランダム、逆順で並べ替えられます。
タブグループやピン留めされたタブにも対応しています。

## Description

ClickTabSort は、Firefox のタブを右クリックメニューから並べ替えるための拡張機能です。
メニューからダイレクトにタブ一覧を並べ替えられます。
クリックした階層だけを並べ替えるか、階層ごと全て並べ替えるか選べます。

以下の並べ替え方法を選べます。

- URL
- タイトル
- 開いた日時
- 最後に見た日時
- ランダム
- 今の逆順

さらに、並べ替え方法ごとに、対象範囲を選べます。

- クリックした階層
- 階層ごと

階層とは、トップレベル、各タブグループ、ピン留めされたタブを指し、それぞれ分けて並べ替えられます。
トップレベルを並べ替えるとき、タブグループは1つのまとまりとして扱われ、グループ内のタブがグループ外のタブと混ざることはありません。
ピン留めされたタブの位置も変わりません。
いずれにおいても、分割ビューは内部順を保ったまま、1つのまとまりとして扱います。
コンテナは区別せずに並べ替えます。

並べ替え方法や対象範囲が1つしかない場合、右クリックメニューが短絡され、より少ないステップで実行できます。

グループや分割ビューが1つのまとまりとして扱われるときは、基本的に先頭タブの情報で並べられます。
設定により、トップレベルでの並べ替え時に、グループのタイトルとしてグループ名を使うこともできます。
グループ名を使う設定が有効な場合、名前のないグループは空文字列として並べ替えます。

開いた日時は Firefox のタブ ID から推定され、Firefox の起動時にリセットされます。

通知を有効にすると、処理の進行状況と完了結果を表示できます。

## プライバシー

ClickTabSort は、タブの URL、タイトル、タブグループ、ピン留め状態、最後に見た日時を比較するためにタブへのアクセス権限を使用します。
閲覧データを収集または送信することはありません。
